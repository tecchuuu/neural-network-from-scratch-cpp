# neural-network-from-scratch-cpp

A neural network built from scratch in C++ — no ML/math libraries, no shortcuts. Every neuron, layer, and eventually every gradient is hand-written.

## Building

```
g++ main.cpp -o main
./main
```

## Roadmap

1. Single neuron
2. Layer of neurons
3. Chain multiple layers into a full forward pass
4. Random weight initialization
5. Loss function
6. Backpropagation
7. Gradient descent + training loop
8. Train on a real dataset
